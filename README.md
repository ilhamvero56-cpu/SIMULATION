# Animasi Alur Kerja Regenerative Braking

Animasi interaktif alur kerja regenerative braking pada mobil listrik, lengkap dengan panel monitoring parameter.

Tekan tombol **Berikutnya**, **Sebelumnya**, atau angka 1-6 untuk berpindah langkah. Nilai pada panel monitoring adalah simulasi untuk ilustrasi, bukan data kendaraan nyata.

## Isi

- `index.html`: halaman animasi (HTML, CSS, dan JavaScript dalam satu file)
- `assets/mobil-listrik.jpg`: gambar mobil yang menjadi latar animasi

## Menayangkan lewat GitHub Pages

1. Buat repository baru di GitHub, lalu unggah semua isi folder ini (`index.html`, `README.md`, dan folder `assets`).
2. Buka **Settings > Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Simpan. Beberapa menit kemudian halaman tersedia di `https://NAMA-ANDA.github.io/NAMA-REPO/`.

Fonta Lato dimuat dari Google Fonts, jadi perlu koneksi internet saat halaman dibuka.
